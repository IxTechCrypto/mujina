# Brag Plan: MUJINA

## What is this app?
Mujina is the first truly open-source Bitcoin mining firmware written in Rust—engineered to drive any ASIC hashboard from any vendor on any control board, completely free of proprietary lock-in and dev fees.

## The angle
Industrial cyberpunk mining rebellion. Every miner bought their hardware, but closed firmware vendors skim a 2-4% dev fee and control the silicon with black-box software. Mujina liberates the hardware: 100% open-source, written in memory-safe Rust, with a hyper-detailed real-time telemetry dashboard and zero dev fee.

## Hook (first 2-3 seconds)
Deep cyber grid background with neon scanline shimmer. A massive cyan and magenta headline slams in:
"YOU BOUGHT THE HARDWARE."
"WHY IS SOMEONE ELSE CONTROLLING THE FIRMWARE?"
Backed by a heavy industrial bass drop and an impact resonance hit.

## Key moments (the middle)
- **Zero Dev Fee & Universal Silicon**: Showcase support for Bitaxe Gamma, BM1370, BM1362, EmberOne00, and Antminer S19 with glowing neon status cards: "ZERO DEV FEE" • "ANY HASHBOARD" • "WRITTEN IN RUST".
- **The Architecture**: Display the architectural system map (`architecture.png`), revealing the modular HAL, Stratum v1 protocol engine, ASIC drivers, and documented REST API.
- **The Fleet Monitor UI**: Recreate the futuristic neon dashboard: Live Hashrate (TH/s), J/TH Efficiency, voltage auto-tune, chip temperature, and share verification.

## Outro / punchline
"MUJINA // OWN YOUR FIRMWARE."
"Run your hashboards without permission."
GitHub link and terminal command (`cargo run --bin mujina-minerd`).

## User flow worth showing
1. **Entry**: Boot `mujina-minerd` on any control board (or test locally with CPU miner).
2. **Key Action**: Connects to Stratum v1 pool → Real-time frequency & voltage chip autotuning.
3. **Result**: Real-time fleet telemetry streaming at 0% fee diversion.
